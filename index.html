Privacy

Browser-only utilities. No server — nothing you type leaves your browser. Page views are counted with Google Tag Manager (GTM-NWTM4N47); no input, secret or token is sent. Each tool has its own page / filename, so you can link straight to it.

JWT signing / verifying with a real secret is demo-only in a browser. Don't paste a production secret into any web page — signing real tokens belongs on a server. Decoding a JWT is safe: it only reads the token.
