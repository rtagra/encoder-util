# Google Tag Manager — Do Not Alter The Tag

**Instruction for any agent or developer updating this code:**

Do NOT alter, reformat, move, or replace the Google Tag Manager snippet
in the `<head>` of every HTML page in this repo.

The tag was generated by Google, ID `GTM-NWTM4N47`, and must stay exactly as-is:

```html
<script async src="https://www.googletagmanager.com/gtm.js?id=GTM-NWTM4N47"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
</script>
```

If analytics needs changing, change it in Google Tag Manager, not in these files.

Privacy: only page views are counted. No tool input, JWT, secret, or
encoded/decoded text is ever sent to Google.

## Adding a new page — always add the Google Tag

Every new HTML page in this repo MUST include the GTM snippet above,
verbatim, in its `<head>`, with the DO NOT ALTER comment above it.

Checklist for a new page:
1. Copy the snippet from `new-page-template.html` (or any existing page) — do not retype it.
2. Paste it in `<head>`, exactly as-is, ID `GTM-NWTM4N47`.
3. Add the page to the menu (`<nav>`) in every HTML file, marking it `class="active"` on its own page.
4. Add it to the home-page grid in `index.html` and to the tools table in `README.md`.
5. Verify the tag is present before pushing: `grep -c GTM-NWTM4N47 <new-page>.html` must return 2.
6. Add SEO to the new page too (unique title, meta description, canonical, Open Graph, JSON-LD) and add it to `sitemap.xml` — see README.md > SEO.

## Exception: openapi.html has NO tag

`openapi.html` must NOT have the Google Tag Manager snippet, by design.
Bank OpenAPI specs are confidential, so no page view is sent while
working on that page. Do not add the tag to `openapi.html`, even though
every other page has it. Swagger UI and the YAML parser on that page
are vendored locally in `vendor/` — no CDN, no external script.
